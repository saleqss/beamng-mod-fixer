## 🔍 Почему ломаются фары у модов в BeamNG.drive?

После графических обновлений движка BeamNG (внедрение PBR 1.5 материалов, кластеризованного освещения Clustered Forward+ и переработанных теней):

1. **Эффект самозатенения (Self-Shadow Occlusion)**: в движке Torque3D/DirectX источники света (spotlights) со значением `"lightCastShadows": true` рассчитывают динамическую карту теней прямо из точки своего расположения. У модовых машин координаты фары (`translation` или `baseTranslation`) практически всегда находятся внутри стекла фары, отражателя или непосредственно за геометрией бампера.
2. **Фары светят «внутрь себя»**: когда луч пытается выйти наружу, движок рендеринга видит перед источником света собственный полигон бампера/стекла и проецирует 100% глухую черную тень вперед. В итоге фара внешне может едва тлеть текстурой, но луч света на дорогу **не падает вообще** — ночью впереди абсолютная тьма!
3. **Падение FPS и лаги**: расчет теней для 2–6 динамических прожекторов на каждой машине создает огромную нагрузку на CPU (вызовы отрисовки draw calls).
4. **Решение проблемы**: замена `"lightCastShadows": true` на `false` в файлах `.jbeam` отключает самозатенение фары. Свет начинает свободно и ярко освещать дорогу и окружающие объекты, а частота кадров (FPS) ночью возрастает на **15–30%**!

## ✨ Возможности утилиты

- 🔦 **Автоматическое исправление модов**: потоковое сканирование всех `.zip` архивов в папке модов BeamNG и замена `"lightCastShadows": true` на `false` во всех `.jbeam` файлах.
- ⚡ **Атомарная потоковая перезапись**: архивы обновляются напрямую (*in-place*) через временный файл. Никаких лишних копий, не захламляет диск, сохраняет 100% исходной структуры папок, текстур (`.dds`), 3D-моделей (`.dae`) и звуков (`.wav`).
- 🛡️ **Отказоустойчивость**: защита от сбоев — корректный пропуск запароленных, поврежденных или заблокированных игрой архивов (например, если BeamNG запущена в момент работы скрипта).
- 🌐 **Поддержка кодировок**: корректная работа с UTF-8 с BOM, стандартным UTF-8, Windows-1251 (русскоязычные комментарии в модах) и Windows-1252.
- 🚀 **Деплой оптимизации графики**: применение сбалансированного пресета в `settings.json` и `game-settings.json` (`facesPerUpdate: 2`, `textureSize: 512`, оптимизация теней) — устраняет микрофризы и статтеры, сохраняя картинку великолепной!
- 🧹 **Очистка кэша шейдеров**: удаление устаревших и сбойных шейдеров (`.d3dcsx`, `.db`) в папке `temp/` без риска повредить конфигурации машин (`.pc`) или моды.
- 💻 **Работает без сторонних библиотек**: написан на чистом стандартном Python 3.10+, не требует `pip install` для обычного использования.
- 🧪 **185+ автоматических тестов**: полное покрытие логики тестами `pytest` по всем пограничным и состязательным сценариям.

## 🚀 Быстрый старт

### 1. Системные требования
- Windows 10/11 (или Linux / Steam Deck Proton)
- Установленный Python 3.10 или новее ([официальный сайт python.org](https://www.python.org/downloads/))

### 2. Запуск в интерактивном режиме
Скачайте или склонируйте репозиторий, откройте терминал (PowerShell или командную строку) в папке со скриптом и запустите:

```bash
python -m beamng_mod_fixer
```

Скрипт автоматически найдет папку с модами BeamNG.drive (например, `%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods`) и выведет удобное меню:

```text

 | __ )| ____|  / \  |  \/  | \ | |/ ___|    |  _ \|  _ \|_ _\ \   / /
 |  _ \|  _|   / _ \ | |\/| |  \| | |  _ ____| | | | |_) || | \ \ / / 
 | |_) | |___ / ___ \| |  | | |\  | |_| |____| |_| |  _ < | |  \ V /  
 |____/|_____/_/   \_\_|  |_|_| \_|\____|    |____/|_| \_\___|  \_/   
             Mod Headlight Fixer & Graphics Optimizer v1.0.0
======================================================================

Обнаружена папка BeamNG: C:\Users\user\AppData\Local\BeamNG\BeamNG.drive\current

Выберите действие:
  1) Исправить свет фар во всех модах (рекомендуется)
  2) Оптимизировать настройки графики (высокий FPS + сочная картинка)
  3) Очистить кэш шейдеров и текстур
  4) Выполнить ВСЕ действия (исправить моды + оптимизировать + очистить кэш)
  5) Выход

Введите номер [1-5] (по умолчанию: 4): 
```

## 🛠️ Запуск через командную строку (CLI)

Для автоматизации, пакетных сценариев или мод-менеджеров:

### Популярные команды

| Задача | Команда |
|---|---|
| **Исправить все моды** | `python -m beamng_mod_fixer --fix-mods` |
| **Указать свою папку модов** | `python -m beamng_mod_fixer --mods-dir "D:\BeamNG\mods" --fix-mods` |
| **Оптимизировать графику** | `python -m beamng_mod_fixer --optimize-graphics` |
| **Очистить кэш шейдеров** | `python -m beamng_mod_fixer --clean-cache` |
| **Сделать всё сразу (All-in-One)** | `python -m beamng_mod_fixer --all` |
| **Тестовый прогон (без изменения файлов)** | `python -m beamng_mod_fixer --all --dry-run` |
| **Тихий режим (для скриптов)** | `python -m beamng_mod_fixer --fix-mods --quiet` |

### Справка по всем аргументам

```text
Пути к директориям:
  -m, --mods-dir ПУТЬ       Путь к папке модов BeamNG.
  -s, --settings-dir ПУТЬ   Путь к папке настроек (содержит settings.json).
  -c, --cache-dir ПУТЬ      Путь к временному кэшу (temp/ или cache/).

Действия:
  --fix-mods                Сканировать и исправить фары в модах.
  --optimize-graphics       Применить пресет графической оптимизации.
  --clean-cache             Очистить скомпилированные шейдеры в temp/.
  -a, --all                 Выполнить все три действия разом.

Параметры:
  --preset {balanced,performance,ultra}
                            Пресет графики (по умолчанию: balanced).
  --dry-run                 Проанализировать файлы без внесения изменений.
  --no-backup               Не создавать резервную копию .bak при оптимизации.
  -q, --quiet               Отключить баннеры и подробные логи.
  --verbose                 Включить подробный вывод диагностики.
  -v, --version             Показать версию и выйти.
```

## 🎮 Подробно об оптимизации графики BeamNG

В стандартном профиле "Ультра" в BeamNG часто возникают микрофризы даже на мощных видеокартах (RTX 3060 Ti / 3070 / 4070) из-за избыточных вызовов динамических отражений.

Наш **Сбалансированный пресет (Balanced)** вносит точечные корректировки:

| Параметр | По умолчанию (Ультра) | Оптимизировано | Эффект |
|---|---|---|---|
| `GraphicDynReflectionFacesPerupdate` | `6` (все 6 граней куба каждый кадр) | `2` (с чередованием) | **+25–40% FPS** при виде из кабины и от 3-го лица |
| `GraphicDynReflectionTexsize` | `1024` и выше | `512` | Предотвращает переполнение VRAM и лаги при загрузке текстур |
| `GraphicShadowsQuality` | `Ultra` (перегружает CPU) | `High` + мягкая фильтрация | Визуально неотличимо от Ultra, убирает просадки 1% Low |
| `GraphicMaxDecalCount` | `10000+` | `6000` | Предотвращает утечки памяти от следов шин при долгих заездах |
| `GraphicAntialias` | Размытое TAA/FXAA | `SMAA 4x` + 16x Анизотропия | Четкие текстуры и гладкие грани без "мыла" |

*Перед изменением настроек скрипт автоматически создает резервную копию `settings.json.bak` и копию с отметкой времени `settings.json.backup_ГГГГММДД_ЧЧММСС`.*

## 👨‍💻 Ручное исправление для авторов модов

Если вы создаете моды для BeamNG, вот как исправить оптику вручную:

1. Откройте ZIP-архив вашего мода и найдите JBeam-файл оптики в `vehicles/<имя_машины>/.../*.jbeam` (например, `*_headlights.jbeam` или `*_body.jbeam`).
2. Найдите секцию `props` или `spotlights`.
3. Найдите блок настроек фары:
   ```json
   {
       "lightInnerAngle": 70,
       "lightOuterAngle": 80,
       "lightColor": {"r": 235, "g": 245, "b": 245, "a": 255},
       "lightCastShadows": true,   // <--- ЗАМЕНИТЕ НА false!
       "flareName": "vehicleHeadLightFlare",
       "cookieName": "art/special/BNG_light_cookie_headlight.dds"
   }
   ```
4. Замените `"lightCastShadows": true` на `"lightCastShadows": false`.
5. Убедитесь, что `cookieName` указывает на `art/special/BNG_light_cookie_headlight.dds`, а не на старый путь `art/shapes/lights/...`.
6. Сохраните файл и перепакуйте мод.
