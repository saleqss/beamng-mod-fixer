## ⚡ Быстрая установка и запуск

### 1. Установка одной командой через Git
Установите напрямую из репозитория GitHub через `pip`:

```bash
pip install git+https://github.com/saleqss/beamng-mod-fixer.git
```

*Либо склонируйте и установите в режиме разработки:*
```bash
git clone https://github.com/saleqss/beamng-mod-fixer.git
cd beamng-mod-fixer
pip install -e .
```

### 2. Запуск из любого терминала
Откройте **PowerShell**, **Командную строку** или **Терминал** и введите команду:

```bash
agy-gbeam-fix
```

*(Также зарегистрированы короткие алиасы: `gbeam-fix` и `agy-beam`)*

## 💡 Калибровка освещения: почему старые фиксы давали белые фары сзади и ядерные красные диски?

### 1. Баг белого света сзади при включении фар (Решено!)
В парсере JBeam BeamNG таблица `props` использует механизм **наследования шаблонов**: если строка таблицы не указывает параметр явно, она наследует его из предыдущего шаблонного словаря.
Авторы модов часто объявляли шаблон фонаря заднего хода с белым цветом:
```json
{"lightColor": {"r": 255, "g": 255, "b": 255, "a": 255}}
```
После чего объявляли габаритные огни `lowhighbeam` или `taillight` без явного `lightColor`. В результате при включении ближнего света корма автомобиля заливала землю ослепительным **белым прожектором заднего хода**!
> **Решение GBEAM FIX**: алгоритм принудительно внедряет откалиброванный цвет в каждую строку задней оптики:
> - Стоп-сигналы и габариты: насыщенный красный `{"r": 255, "g": 20, "b": 20, "a": 255}`
> - Задний ход: теплый белый `{"r": 255, "g": 250, "b": 220, "a": 255}`
> - Поворотники: янтарный `{"r": 255, "g": 140, "b": 15, "a": 255}`

### 2. Устранение ядовито-красных дисков на асфальте
Грубые значения яркости ($0.85 - 1.2$) и линейное затухание создавали на земле неестественные, ослепляющие красные круги с резкими краями.
> **Решение GBEAM FIX**: 
> - Яркость габаритов снижена до реалистичных `0.12`
> - Яркость стоп-сигналов сбалансирована на `0.35`
> - Внедрено квадратичное затухание `lightAttenuation: {"x": 0, "y": 1, "z": 2}` для мягкого градиента света по асфальту
> - Принудительно отключены тени задних фонарей (`lightCastShadows: false`), исключая черные дыры от бампера.

### 3. Пробивающий дальний свет (Устранение слепого дальнего)
В старых модах дальний свет светил на жалкие $3-5\text{ метров}$, как тусклый фонарик. GBEAM FIX автоматически бустит слабые дальние лучи:
- Дальность: `lightRange: 120.0m`
- Яркость: `lightBrightness: 2.2`
- Угол конуса: `lightOuterAngle: 55.0°`

## 🎨 Доктор материалов: устранение оранжевой сетки "NO TEXTURE"

1. **Распаковка вложенных папок модов**: многие авторы упаковывают моды с корневой папкой (например, `SuperCar_v1/vehicles/supercar/...`). Файловая система игры PhysFS не может найти текстуры и выдает оранжевую сетку. GBEAM FIX автоматически определяет и устраняет эту вложенность, приводя структуру к `vehicles/...`.
2. **Конвертация `materials.cs` в JSON 1.5 PBR**: преобразует старый TorqueScript в официальный стандарт PBR.
3. **Нормализация путей VFS**: переводит обратные слэши `\` в `/`, убирает невалидные пути.
4. **Сверка форматов**: автоматически связывает `.png` и оптимизированные `.dds`.

## ⚡ Фоновый автоустановщик модов из Загрузок

GBEAM FIX включает встроенный сервис `ModWatcher`, который может работать в фоновом режиме:
1. Следит за системной папкой `Downloads`.
2. Дожидается 100% завершения скачивания браузером (игнорирует `.crdownload`, `.tmp`, `.part`).
3. Проверяет сигнатуры модов BeamNG (`vehicles/`, `levels/`, `art/` и др.) и отсекает посторонние архивы.
4. Распаковывает вложенные папки, перемещает мод в папку игры `%LOCALAPPDATA%/BeamNG/BeamNG.drive/current/mods/`.
5. **На лету применяет полный 7-этапный комплекс исправления**! Скачали мод — он уже в игре и на 100% исправлен!

Управление автоустановщиком доступно через пункт меню **`W`** или флаг командной строки **`--watch`**.

## 🚀 4 пресета графики и FPS

| Пресет | Описание | Для кого |
|---|---|---|
| **`ultra-max-fps`** (По умолчанию) | 100% Ultra: 1024px отражения, 4x тени, 16x анизотропия, умный буст 3 граней | Мощные ПК / RTX / 2K-4K / Максимальная графика |
| **`medium-60fps`** | Сбалансированный пресет для стабильных 60 FPS без микрофризов | Средние системы |
| **`low-weak`** | Оптимизированные тени и частицы для бюджетных видеокарт | Бюджетные ПК |
| **`potato-ultra-weak`** | Экстремальный буст производительности для слабых ноутбуков и встроек | Интегрированные GPU / Старые ПК |

Перед каждым изменением создается автоматический бэкап настроек (`.bak`), который можно восстановить в 1 клик.

Запустите команду `agy-gbeam-fix`:

```text
MAIN CONTROL MENU (ГЛАВНОЕ МЕНЮ):
  1. 🚀 ГЛОБАЛЬНЫЙ ФИКС В 1 КЛИК (Оптика + Текстуры + Физика + Звук + Lua + Графика + Кэш)
  2. 💡 Студия оптики и фар (Баланс дальний/ближний, углы лучей, современные текстуры)
  3. 🎨 Доктор материалов и текстур (Устранение NO TEXTURE, materials.cs -> 1.5 JSON, пути VFS)
  4. ⚙️ Ремонт трансмиссии и физики (Разморозка дифференциалов, давление в шинах, сцепление)
  5. 🔊 Защита звука и Lua (Перевод на FMOD BeamNG, защита от вылетов Lua)
  6. 🚀 Оптимизатор графики и FPS (Пресеты Ultra-Max-FPS, 60FPS-Balanced, Low, Картошка)

  W. ⚡ Фоновый автоустановщик модов из Загрузок
  L. 🌐 Сменить язык / Change Language (Русский / English)
  0. 🚪 Выход
```

- **Пункт 1 (Глобальный фикс в 1 клик)**: выполняет полную диагностику, ремонт модов, деплой графики и очистку кэша. По завершении открывает **Post-Fix Results Studio** с подробным отчетом, из которой нажатие `1` или `Enter` чисто возвращает в Главное меню!
- **Пункт L**: мгновенно переключает язык интерфейса между русским и английским с сохранением в `~/.beamng_mod_fixer/config.json`.
- **Чистая типографика**: меню избавлено от лишних скобок и спама символов.

## 🛠️ Параметры командной строки (CLI)

```bash
# Глобальный фикс в 1 клик (Все 7 этапов + ультра-графика + очистка кэша)
agy-gbeam-fix --all

# Запуск фонового автоустановщика модов из Загрузок
agy-gbeam-fix --watch

# Установка языка интерфейса
agy-gbeam-fix --lang ru
agy-gbeam-fix --lang en

# Применить пресет графики
agy-gbeam-fix --optimize-graphics --preset ultra-max-fps
agy-gbeam-fix --optimize-graphics --preset medium-60fps
agy-gbeam-fix --optimize-graphics --preset potato-ultra-weak

# Деплой готовых пресетов ReShade (Medium Optimal, Low Fast, Potato Boost, Ultra Photoreal)
agy-gbeam-fix --deploy-reshade medium-optimal
agy-gbeam-fix --deploy-reshade ultra-photoreal

# Показать обнаруженные пути BeamNG и статус
agy-gbeam-fix --show-paths

# Очистить кэш шейдеров (.d3dcsx, .db)
agy-gbeam-fix --clean-cache

# Безопасный предпросмотр без изменения файлов (Dry Run)
agy-gbeam-fix --all --dry-run
```
