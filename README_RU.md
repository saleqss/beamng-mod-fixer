Установить утилиту можно прямо из GitHub репозитория одной командой через pip:


## 🔍 В чем была проблема: почему старые фиксеры ломали рабочие фары?

Пользователи часто сталкивались с ситуацией:
- **В модах, где фары работали — они переставали нормально работать** (исчезали тени дальнего света, свет пробивал салон и слепил водителя от 1-го лица).
- **В сломанных модах — свет так и не появлялся**.

### 1. Проблема разделения ближнего и дальнего света
- В движке BeamNG (Torque3D Clustered Forward+ PBR) стандартные машины используют `"lightCastShadows": false` для **ближнего света** (lowbeam), чтобы свет не перекрывался бампером, и `"lightCastShadows": true` для **дальнего света** (highbeam).
- При топорной замене всех теней на `false`:
  - **Дальний свет теряет тени**, свет пробивает кузов насквозь и заливает белым светом приборную панель в салоне, ослепляя игрока.
  - Теряется глубина ночного освещения на дистанции.

### 2. Почему в других модах фары не начинали светить?
Даже при отключенных тенях фара не включится, если в ней есть другие дефекты:
- **Устаревший путь куки-текстуры (Cookie)**: пути вроде `art/shapes/lights/headlight_cookie.dds` были удалены из игры в BeamNG 0.24+. Когда движок не находит эту текстуру (404), источник света просто выключается.
- **Сломанные вспышки (Flares)**: значения `flareName: "none"` или устаревшие `headlightFlare` вместо `vehicleHeadLightFlare`.
- **Инвертированные углы конуса (Spotlight Angles)**: если `lightInnerAngle > lightOuterAngle`, формула затухания света дает нулевую или отрицательную интенсивность — луч физически гаснет!
- **Ошибки в названии электрики**: строки `low_beam` или `high_beam` вместо стандартных `lowbeam` / `highbeam`.
- **Отключение deferredLighting в настройках**: если графика отключает отложенное освещение, игра перестает рендерить множественные динамические источники света.

## ✨ Возможности Smart Fixer

- 🧠 **Умный режим Smart Fix (по умолчанию)**:
  - **Ближний свет и противотуманки**: заменяет `lightCastShadows: true` на `false` (устраняет глухую тень от собственного бампера).
  - **Дальний свет**: СОХРАНЯЕТ `lightCastShadows: true` (сохраняет реалистичные тени и предотвращает засвет салона).
  - **Модернизация текстур куки**: автоматически заменяет старые пути `art/shapes/lights/*` на официальный современный ассет `art/special/BNG_light_cookie_headlight.dds`.
  - **Модернизация вспышек (Flares)**: обновляет `headlightFlare` / `highbeamFlare` до современных `vehicleHeadLightFlare` / `vehicleHighBeamFlare`.
  - **Исправление углов света**: автоматически исправляет перевернутые углы прожектора (`inner > outer`).
  - **Нормализация сигналов**: приводит имена электрики к стандарту (`low_beam` -> `lowbeam`).
- ⚡ **Атомарная потоковая перезапись архивов**: обновление `.zip` файлов на лету без распаковки гигабайтов на диск, сохранение UTF-8 имен файлов, моделей, текстур и звуков.
- 🚀 **Оптимизация графики**: применение сбалансированного пресета (`facesPerUpdate: 2`, `textureSize: 512`, `deferredLighting: true`, `maxLights: 32`) с автоматическим бэкапом `.bak`.
- 🧹 **Очистка кэша шейдеров**: безопасное удаление временных файлов шейдеров (`.d3dcsx`, `.db`) в `temp/` без затрагивания пользовательских конфигураций (`.pc`).
- 🧪 **197 автоматических тестов**: полное покрытие всех сценариев работы без воздействия на локальные файлы игры.

## 🛠️ Запуск через консольные флаги (CLI)

| Действие | Команда |
|---|---|
| **Умный фикс фар (рекомендуется)** | `agy-beam --fix-mods --mode smart` |
| **Классический фикс** | `agy-beam --fix-mods --mode legacy` |
| **Своя папка модов** | `agy-beam --mods-dir "D:\BeamNG\mods" --fix-mods` |
| **Оптимизировать графику** | `agy-beam --optimize-graphics` |
| **Очистить кэш шейдеров** | `agy-beam --clean-cache` |
| **Выполнить всё сразу** | `agy-beam --all` |
| **Симуляция (без изменений)** | `agy-beam --all --dry-run` |
